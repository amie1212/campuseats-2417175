# CampusEats (BICS 3301)

Campus cafeteria pre-ordering application built with React and Vite.

## Vendors & Menus
- **Vendor 1**: Kafe Mahallah Faruq (2417175) — full 9-item menu across Rice, Noodles, Drinks, and Snacks.
- **Other vendors**: to be added by team members — see [CONTRIBUTING.md](CONTRIBUTING.md).

## Running locally
```bash
npm install
npm run dev
```
